Overview

Welcome to the links page! Here you can find various resources and links to sites that are used for the talking game, as well as documents, slideshows, and other things that are related to the game.

If you need access to any of these resources, please send an access request to the email provided, and text the Gamemaster in person (or via GroupMe) to let them know that you have sent a request. This is to make sure access isn't given to non-players, as well as to make sure that people that don't want it don't have it cluttering up their Google Drive.

NOTE: If any of the listed documents contain a NOTICE section at the beginning, PLEASE read it to get context for the document.
